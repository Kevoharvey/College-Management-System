# College Management System

A Spring Boot MVC college dashboard with Thymeleaf views and small examples of sorting and search algorithms.

## Requirements

- Java 17 or newer
- Maven, or the included Maven wrapper

## Run

```bash
./mvnw spring-boot:run
```

Then open:

```text
http://localhost:8080
```

## Test

```bash
./mvnw test
```

## Project Layout

```text
src/main/java/com/college
src/main/resources/templates
src/main/resources/static
src/test/java/com/college
```
